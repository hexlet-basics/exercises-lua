Строки Lua неизменяемы и хранят последовательности байтов. В этом уроке мы запишем текст с управляющими символами и соединим значения оператором `..`.

Одинарные и двойные кавычки равноправны. Обратная косая черта экранирует следующий знак. Например, `\n` создаёт перевод строки, `\t` создаёт табуляцию, а `\\` обозначает саму косую черту.

```lua
print("I'm learning Lua")
print('First\nSecond')
print('C:\\temp')
```

Длинные строки между `[[` и `]]` сохраняют переносы строк и не разбирают такие экранирования. Они удобны для фрагмента текста с несколькими строками. Начальный перенос сразу после `[[` Lua пропускает.

```lua
local message = [[
First
Second]]
print(message)
```

Для конкатенации используется `..`. Оператор не добавляет пробелов и создаёт новое значение. Исходные строки остаются прежними.

```lua
local name = 'Mira'
local greeting = 'Hello, ' .. name .. '!'
print(greeting) -- Hello, Mira!
print(name) -- Mira
```

Оператор принимает строки и числа. Для других типов применяйте `tostring`, если их текстовая запись нужна в сообщении. Арифметическое выражение в строке лучше явно выделить скобками, например `'Total ' .. (12 * 3)`.

Оператор `+` выполняет числовое сложение. При сборке сообщения используйте `..`, чтобы смысл операции был виден из кода.
