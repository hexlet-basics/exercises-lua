В этом уроке мы изучим строки и конкатенацию в Lua. Разберём кавычки, экранирование и запись многострочного текста. Научимся собирать сообщения из текста и значений переменных.

Строки хранят текст как последовательность байтов. Готовое строковое значение нельзя изменить по частям. Для нового сообщения программа создаёт новую строку из прежних значений.

Одинарные и двойные кавычки равноправны. Обратная косая черта экранирует следующий знак. Например, `\n` создаёт перевод строки, `\t` создаёт табуляцию, а `\\` обозначает саму косую черту.

Предположим, в сообщении нужны апостроф, перевод строки и путь с обратной косой чертой. Выберем кавычки и экранирование для каждого случая.

```lua
print("I'm learning Lua")
print('First\nSecond')
print('C:\\temp')
```

Второй вызов выводит две строки, третий выводит одну косую черту.

```text
I'm learning Lua
First
Second
C:\temp
```

Длинные строки между `[[` и `]]` сохраняют переносы строк и не разбирают такие экранирования. Они удобны для фрагмента текста с несколькими строками. Начальный перенос сразу после `[[` Lua пропускает.

```lua
local message = [[
First
Second]]
print(message)
```

Перенос внутри скобок попадает в значение, поэтому вывод занимает две строки.

```text
First
Second
```

Для конкатенации используется `..`. Оператор не добавляет пробелов и создаёт новое значение. Исходные строки остаются прежними. Например, соберём приветствие для человека, чьё имя хранится в `name`.

```lua
local name = 'Mira'
local greeting = 'Hello, ' .. name .. '!'
print(greeting) -- Hello, Mira!
print(name) -- Mira
```

Переменная `greeting` получает строку `'Hello, Mira!'`. Имя в `name` остаётся прежним, потому что конкатенация создала отдельное значение.

Оператор принимает строки и числа. Для других типов применяйте `tostring`, если их текстовая запись нужна в сообщении. Арифметическое выражение в строке лучше явно выделить скобками, например `'Total ' .. (12 * 3)`.

Оператор `+` выполняет числовое сложение. При сборке сообщения используйте `..`, чтобы смысл операции был виден из кода.

Если для числа нужно заданное количество знаков после точки, используйте `string.format`. Например, подготовим цену для вывода с двумя дробными знаками.

```lua
local price = 12.5
print(string.format('Price: %.2f', price)) -- Price: 12.50
```

Формат `%.2f` задаёт два знака после десятичной точки. В отличие от обычной конкатенации, здесь запись числа определяется шаблоном.
