Размер и позиции в строках Lua обычно измеряются в байтах. В этом уроке мы сравним `#` и `utf8.len` и выделим часть ASCII-строки через `string.sub`.

Оператор `#` возвращает количество байтов. В ASCII одна буква занимает один байт. Русские буквы в UTF-8 занимают по два байта.

```lua
print(#'Lua') -- 3
print(#'кот') -- 6
print(utf8.len('кот')) -- 3
```

Функция `utf8.len` считает кодовые точки UTF-8. Видимый символ может состоять из нескольких кодовых точек, например буквы и отдельного знака ударения. Для некорректного UTF-8 функция возвращает `nil` и позицию ошибки.

Функции стандартной библиотеки строк находятся в `string`. Например, `string.sub(text, start, finish)` извлекает байты от начальной позиции до конечной включительно. Первая позиция имеет номер `1`. Отрицательные позиции отсчитываются с конца, где `-1` обозначает последний байт.

```lua
local code = 'lua-2026'
print(string.sub(code, 1, 3)) -- lua
print(string.sub(code, -4)) -- 2026
print(string.upper(code)) -- LUA-2026
```

Тот же вызов строковой функции можно записать через двоеточие. Двоеточие передаёт значение слева первым аргументом. При записи через точку этот аргумент передаётся явно.

```lua
local code = 'lua-2026'
print(code:sub(1, 3)) -- lua
print(string.sub(code, 1, 3)) -- lua
```

`string.format` собирает строку по шаблону. Формат `%.2f` задаёт два знака после десятичной точки.

```lua
print(string.format('%.2f', 12.5)) -- 12.50
```

`string.upper` возвращает новую строку. Для примера используем ASCII, поскольку стандартная строковая библиотека не выполняет полноценное преобразование регистра Unicode.

Применение `string.sub` к русскому тексту по случайным байтовым границам может разрезать символ, записанный несколькими байтами. Для таких задач сначала находят границы кодовых точек через функции `utf8`. В практике урока все позиции относятся к ASCII-строке.
