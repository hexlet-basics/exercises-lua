У числовых операций Lua есть несколько особенностей, которые влияют на перенос знакомых формул. В этом уроке мы сравним деление `/` и `//`, найдём остаток и запишем степень.

Функция `math.type` различает подтипы `integer` и `float`. Lua поддерживает целые числа и числа с плавающей точкой внутри типа `number`. Оператор `/` всегда выполняет деление с результатом с плавающей точкой. Оператор `//` округляет частное вниз.

```lua
print(9 / 2) -- 4.5
print(8 / 2) -- 4.0
print(9 // 2) -- 4
print(-9 // 2) -- -5
print(math.type(9)) -- integer
print(math.type(9 / 2)) -- float
```

Для отрицательного частного округление вниз отличается от отбрасывания дробной части. Остаток `%` согласован с этим правилом: `a % b` равен `a - (a // b) * b`. При положительном делителе он неотрицателен.

```lua
print(17 % 5) -- 2
print(-3 % 2) -- 1
```

Во втором случае `-3 // 2` равно `-2`, поэтому остаток равен `-3 - (-2) * 2`, то есть `1`.

Для возведения в степень используется `^`. Степень имеет более высокий приоритет, чем унарный минус. Поэтому скобки могут изменить результат.

```lua
print(2 ^ 3) -- 8.0
print(-2 ^ 2) -- -4.0
print((-2) ^ 2) -- 4.0
```

Далее по приоритету идут умножение, деление и остаток, затем сложение и вычитание. Скобки позволяют явно выделить нужный расчёт.

Функции библиотеки `math` вызываются через точку. Например, `math.floor(4.7)` возвращает `4`, `math.abs(-5)` возвращает `5`, а `math.max(3, 8)` возвращает `8`. Их не нужно отдельно подключать в обычном интерпретаторе.
