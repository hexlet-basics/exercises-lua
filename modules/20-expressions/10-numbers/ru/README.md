В этом уроке мы изучим числовые операции Lua. Сравним обычное деление с делением с округлением вниз и разберём остаток и возведение в степень. Научимся выбирать операции для расчётов с целыми и дробными результатами.

Lua поддерживает целые числа и числа с плавающей точкой внутри типа `number`. Функция `math.type` различает эти подтипы по именам `integer` и `float`. Выбор операции определяет, нужен ли программе дробный результат или целое частное. Оператор `/` всегда выполняет деление с результатом с плавающей точкой. Оператор `//` округляет частное вниз. Проверим оба оператора на положительных числах и на отрицательном частном.

```lua
print(9 / 2) -- 4.5
print(8 / 2) -- 4.0
print(9 // 2) -- 4
print(-9 // 2) -- -5
print(math.type(9)) -- integer
print(math.type(9 / 2)) -- float
```

Даже деление `8 / 2` возвращает `float`, поэтому результат печатается как `4.0`. В выражении `9 // 2` получаем целое `4`.

Для отрицательного частного округление вниз отличается от отбрасывания дробной части. Остаток `%` согласован с этим правилом. Выражение `a % b` равно `a - (a // b) * b`. При положительном делителе он неотрицателен.

```lua
print(17 % 5) -- 2
print(-3 % 2) -- 1
```

Во втором случае `-3 // 2` равно `-2`, поэтому остаток равен `-3 - (-2) * 2`, то есть `1`.

Для возведения в степень используется `^`. Степень имеет более высокий приоритет, чем унарный минус. Поэтому скобки могут изменить результат.

```lua
print(2 ^ 3) -- 8.0
print(-2 ^ 2) -- -4.0
print((-2) ^ 2) -- 4.0
```

Далее по приоритету идут умножение, деление и остаток, затем сложение и вычитание. Скобки позволяют явно выделить нужный расчёт.

Функции библиотеки `math` вызываются через точку. Например, `math.floor(4.7)` возвращает `4`, `math.abs(-5)` возвращает `5`, а `math.max(3, 8)` возвращает `8`. Их не нужно отдельно подключать в обычном интерпретаторе.
