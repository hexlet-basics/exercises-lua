В этом уроке мы изучим поиск и замену в строках Lua. Разберём точный поиск через `string.find` и замену по шаблону через `string.gsub`. Научимся находить разделитель и приводить текстовый код к нужной записи.

Для поиска фрагмента не всегда известна его позиция. Например, перед выделением части кода товара сначала нужно найти разделитель. Функция `string.find` ищет в строке и возвращает позицию начала найденного фрагмента. Если фрагмента нет, результатом будет `nil`.

Предположим, код товара хранится как `'lua.2026'`, и нам нужно узнать позицию точки. Четвёртый аргумент `true` включает точный поиск, при котором точка обозначает саму себя. Третий аргумент `1` задаёт начало поиска с первого байта.

```lua
local code = 'lua.2026'
local position = string.find(code, '.', 1, true)
print(position) -- 4
print(string.find(code, '/', 1, true)) -- nil
```

Точка находится в четвёртом байте, поэтому `position` получает `4`. Косой черты в коде нет, и второй поиск возвращает `nil`. Все символы примера относятся к ASCII, поэтому их позиции совпадают с номерами байтов.

Для изменения найденных фрагментов служит `string.gsub(text, pattern, replacement)`. Она возвращает новую строку, в которой совпадения с шаблоном заменены на `replacement`. Исходная строка остаётся прежней.

Шаблоны Lua имеют собственные правила и отличаются от регулярных выражений других языков. Например, точка в шаблоне означает любой символ. Чтобы обозначить именно точку, перед ней ставят `%`. Для простого поиска текста через `string.find` можно отключить шаблоны аргументом `true`, как в примере выше. У `string.gsub` такого аргумента нет.

Допустим, для передачи кода товара в другую систему требуется дефис вместо точки. Заменим разделитель и приведём буквы к верхнему регистру.

```lua
local code = 'lua.2026'
local normalized = string.gsub(code, '%.', '-')
print(string.upper(normalized)) -- LUA-2026
print(code) -- lua.2026
```

В `normalized` попадёт строка `'lua-2026'`. Вызов `string.upper` подготовит её для вывода, а переменная `code` сохранит исходное значение.

`string.gsub` заменяет все совпадения с шаблоном. Например, для строки `'lua.guide.txt'` тот же шаблон даст `'lua-guide-txt'`. Если совпадений нет, текст останется прежним.
