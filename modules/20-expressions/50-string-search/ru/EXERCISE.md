В редакторе объявлена переменная `code` со строковым кодом товара. Все его символы относятся к ASCII. Найдите позицию точки с помощью `string.find` в режиме точного поиска и выведите её. Затем замените все точки на дефисы через `string.gsub` и выведите полученный код в верхнем регистре.

Для исходного значения `'lua.2026'` программа должна вывести две строки.

```text
4
LUA-2026
```

Исходное значение `code` менять не нужно.
