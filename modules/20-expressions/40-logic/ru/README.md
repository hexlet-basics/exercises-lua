В этом уроке мы изучим сравнения и логические операторы Lua. Разберём выбор значений через `and` и `or` и проверку истинности через `not`. Научимся подставлять значение по умолчанию с учётом нуля и логического `false`.

Сравнение проверяет отношение между значениями. Логические операторы позволяют объединять проверки и выбирать значение по их результатам. Это пригодится, например, для настройки, которую пользователь может оставить незаполненной.

Сравнения записываются через `==`, `~=`, `<`, `>`, `<=` и `>=`. Оператор `~=` обозначает неравенство. Результат сравнения имеет тип `boolean`. Значение `true` обозначает истину, `false` обозначает ложь.

Проверим неравенство чисел и равенство числа его строковой записи.

```lua
print(3 ~= 4) -- true
print(3 == '3') -- false
```

Числа `3` и `4` различаются, поэтому первое сравнение даёт `true`. Число `3` и строка `'3'` имеют разные типы, и сравнение даёт `false`.

При проверке истинности Lua считает ложными только `false` и `nil`. Число `0` и пустая строка считаются истинными. Это влияет на выражения с `and`, `or` и `not`.

```lua
print(not nil) -- true
print(not 0) -- false
print(not '') -- false
```

Операторы `and` и `or` возвращают один из своих операндов. `a or b` возвращает `a`, если он истинный, иначе возвращает `b`. `a and b` возвращает `a`, если он ложный, иначе возвращает `b`. Правая часть вычисляется только тогда, когда нужна для результата.

Предположим, имя гостя и лимит можно взять из настроек, а при отсутствии значения нужны `'Guest'` и `10`. Посмотрим, как выбор зависит от значения слева.

```lua
print(nil or 'Guest') -- Guest
print(0 or 10) -- 0
print(false and 'Ready') -- false
print('' or 'Guest') -- empty line
```

Выражение с `nil` выбирает `'Guest'`. Ноль и пустая строка сохраняются, поскольку считаются истинными. Выражение с `false and` заканчивается на левом операнде и возвращает `false`.

Так можно подставить значение по умолчанию вместо `nil`. Но `or` также заменит `false`, поэтому для логической настройки с допустимым `false` нужна явная проверка отсутствия.

```lua
local enabled = false
print(enabled or true) -- true
print(enabled == nil) -- false
```

Выражение `enabled or true` потеряло заданное `false`, а сравнение с `nil` показывает, что настройка задана.

В выражении `condition and x or y` значение `x`, равное `false` или `nil`, приведёт к выбору `y`.

```lua
print(true and false or 'fallback') -- fallback
```

Когда нужны такие результаты, используйте обычное ветвление. По приоритету `not` выполняется раньше `and`, а `and` раньше `or`.
