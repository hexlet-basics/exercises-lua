Условия Lua считают ложными только `false` и `nil`. В этом уроке мы разберём логические операторы и выберем значение по умолчанию без потери числового нуля.

Сравнения записываются через `==`, `~=`, `<`, `>`, `<=` и `>=`. Оператор `~=` обозначает неравенство. Результат сравнения имеет тип `boolean`.

```lua
print(3 ~= 4) -- true
print(3 == '3') -- false
```

При проверке истинности число `0` и пустая строка считаются истинными. Это влияет на выражения с `and`, `or` и `not`.

```lua
print(not nil) -- true
print(not 0) -- false
print(not '') -- false
```

Операторы `and` и `or` возвращают один из своих операндов. `a or b` возвращает `a`, если он истинный, иначе возвращает `b`. `a and b` возвращает `a`, если он ложный, иначе возвращает `b`. Правая часть вычисляется только тогда, когда нужна для результата.

```lua
print(nil or 'Guest') -- Guest
print(0 or 10) -- 0
print(false and 'Ready') -- false
print('' or 'Guest') -- empty line
```

Так можно подставить запасное значение вместо `nil`. Но `or` также заменит `false`, поэтому для логической настройки с допустимым `false` нужна явная проверка отсутствия.

В выражении `condition and x or y` значение `x`, равное `false` или `nil`, приведёт к выбору `y`. Когда нужны такие результаты, используйте обычное ветвление из модуля управления потоком. По приоритету `not` выполняется раньше `and`, а `and` раньше `or`.
