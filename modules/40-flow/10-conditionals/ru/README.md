В этом уроке мы изучим ветвление в Lua. Разберём выбор ветви через `if` и ранний возврат через `return`. Научимся обрабатывать особые случаи до основного вычисления.

Ветвление выбирает инструкции по условию. В Lua оно записывается через `if`, `then`, `elseif`, `else` и `end`. Условие каждой ветви определяет, когда нужно выполнить её код.

Предположим, программа подбирает подпись погоды по температуре. Функция `weather` вернёт одну из трёх подписей.

```lua
local function weather(temperature)
    if temperature < 0 then
        return 'freezing'
    elseif temperature < 20 then
        return 'cool'
    else
        return 'warm'
    end
end

print(weather(12)) -- cool
```

Для температуры `12` первое условие `temperature < 0` ложно, а второе `temperature < 20` истинно. Поэтому `weather(12)` возвращает `'cool'`. Lua проверяет условия сверху вниз и выполняет первую подходящую ветвь.

`elseif` пишется слитно. Ветвление закрывает один `end`, а функцию закрывает другой. Скобки вокруг условий не обязательны. Отступы помогают читать тело, сами блоки определяются ключевыми словами.

Иногда особый случай нужно обработать до основной работы. Например, подпись суммы можно собрать только после проверки, что сумма передана. Ранний `return` завершит вызов при отсутствии данных и позволит записать основной расчёт без вложенного `else`.

```lua
local function label(amount)
    if amount == nil then
        return 'missing'
    end
    return 'Amount ' .. amount
end

print(label(nil)) -- missing
print(label(5)) -- Amount 5
```

Вызов `label(nil)` попадает в первую ветвь и возвращает `'missing'`, не доходя до конкатенации. Для `label(5)` условие ложно, поэтому функция собирает строку `'Amount 5'`. После раннего `return` оставшиеся инструкции функции не выполняются.

Для проверки диапазона условия объединяются через `and`, например `age >= 18 and age < 65`. В ошибочном варианте файла _index.lua_ два сравнения записаны подряд.

<!-- lint-code-blocks: skip — цепочка сравнений сравнивает логическое значение с числом -->

```text
local age = 30
print(18 <= age < 65)
```

Первое сравнение возвращает `true`. Второе пытается сравнить это логическое значение с числом `65`, и выполнение останавливается.

```text
lua: index.lua:2: attempt to compare boolean with number
```

Короткое замыкание помогает защитить операцию. В условии `amount ~= nil and amount > 0` правая часть выполняется только для существующего значения. Сами `0` и `''` в условиях Lua истинны.
