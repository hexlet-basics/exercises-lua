Ветвление Lua записывается через `if`, `then`, `elseif`, `else` и `end`. В этом уроке мы выберем одну из ветвей и завершим функцию сразу после получения ответа.

```lua
local function weather(temperature)
    if temperature < 0 then
        return 'freezing'
    elseif temperature < 20 then
        return 'cool'
    else
        return 'warm'
    end
end

print(weather(12)) -- cool
```

Lua проверяет условия сверху вниз и выполняет первую подходящую ветвь. `elseif` пишется слитно. Ветвление закрывает один `end`, а функцию закрывает другой. Скобки вокруг условий не обязательны. Отступы помогают читать тело, сами блоки определяются ключевыми словами.

`return` позволяет обойтись без вложенного `else`, если ответ уже найден.

```lua
local function label(amount)
    if amount == nil then
        return 'missing'
    end
    return 'Amount ' .. amount
end
```

После раннего `return` оставшиеся инструкции функции не выполняются. Это удобно для проверки отсутствующих данных до основного расчёта.

Для диапазона используйте `and`, например `age >= 18 and age < 65`. Запись `18 <= age < 65` сначала получит логическое значение и затем попытается сравнить его с числом.

Короткое замыкание помогает защитить операцию. В условии `amount ~= nil and amount > 0` правая часть выполняется только для существующего значения. Напомним, что сами `0` и `''` в условиях Lua истинны.
