В этом уроке мы изучим числовой цикл `for` в Lua. Разберём границы диапазона и шаг перебора. Научимся выбирать значения диапазона для накопления результата.

Числовой `for` перебирает значения от начальной границы до конечной с заданным шагом. Такой цикл подходит, когда диапазон известен до начала работы. В отличие от границ некоторых других языков конечное значение включено в перебор.

Предположим, программе нужно пронумеровать три страницы. Переберём номера от `1` до `3`.

```lua
for index = 1, 3 do
    print(index)
end
```

Программа выведет `1`, `2` и `3`. Переменная `index` локальна для цикла. Границы и шаг вычисляются перед началом перебора. Управляющая переменная доступна только для чтения. Присвоить ей другое значение внутри тела нельзя.

Третье выражение задаёт шаг, по умолчанию он равен `1`. Отрицательный шаг позволяет двигаться в обратную сторону.

```lua
for index = 5, 1, -2 do
    print(index)
end
```

Программа выведет `5`, `3` и `1`, каждое число на отдельной строке.

Если нужно получить общий результат перебора, его можно накапливать в переменной перед циклом. Например, посчитаем сумму номеров трёх страниц.

```lua
local total = 0
for number = 1, 3 do
    total = total + number
end
print(total) -- 6
```

Переменная `total` объявлена вне цикла, поэтому сохраняет значение между проходами. Каждый проход прибавляет очередной `number`, а после цикла `total` содержит сумму `1 + 2 + 3`.

При положительном шаге цикл заканчивается после превышения конечной границы. При отрицательном он заканчивается после перехода ниже неё. Если начальное значение уже лежит за конечной границей, например в `for index = 3, 1`, тело не выполняется ни разу. Нулевой шаг вызывает ошибку. Например, следующий вариант файла _index.lua_ не может начать перебор.

<!-- lint-code-blocks: skip — числовой цикл с нулевым шагом завершается ошибкой -->

```text
for index = 1, 3, 0 do
    print(index)
end
```

При запуске интерпретатор сообщает, почему такой цикл невозможен.

```text
lua: index.lua:1: 'for' step is zero
```

## Досрочная остановка

Иногда во время перебора становится понятно, что дальнейшие шаги не нужны. В таком случае `break` завершает ближайший окружающий цикл. Для примера ограничим вывод первыми тремя номерами, хотя диапазон содержит десять значений.

```lua
for index = 1, 10 do
    if index > 3 then
        break
    end
    print(index)
end
```

Будут выведены только первые три числа. После `break` выполнение продолжится за `end` цикла. В Lua нет отдельного оператора `continue`. Чтобы пропустить часть тела, можно ограничить её условием `if`.

В следующем примере выведем только нечётные номера из диапазона от одного до пяти. Условие проверит остаток от деления на два.

```lua
for index = 1, 5 do
    if index % 2 == 1 then
        print(index)
    end
end
```

Чётные значения пропускаются, программа выведет `1`, `3` и `5`.
