Числовой цикл `for` в Lua включает конечное значение диапазона. В этом уроке мы зададим шаг перебора и остановим цикл через `break`.

```lua
for index = 1, 3 do
    print(index)
end
```

Программа выведет `1`, `2` и `3`. Переменная `index` локальна для цикла. Границы и шаг вычисляются перед началом перебора. Управляющую переменную внутри тела менять не следует.

Третье выражение задаёт шаг, по умолчанию он равен `1`. Отрицательный шаг позволяет двигаться в обратную сторону.

```lua
for index = 5, 1, -2 do
    print(index) -- 5, then 3, then 1
end
```

При положительном шаге цикл заканчивается после превышения конечной границы. При отрицательном он заканчивается после перехода ниже неё. Если начальные границы не допускают ни одного прохода, тело сразу пропускается. Нулевой шаг в Lua 5.4 вызывает ошибку.

`break` завершает ближайший окружающий цикл.

```lua
for index = 1, 10 do
    if index > 3 then
        break
    end
    print(index)
end
```

Будут выведены только первые три числа. После `break` выполнение продолжится за `end` цикла. В стандартном Lua 5.4 нет отдельного оператора `continue`. Чтобы пропустить часть тела, можно ограничить её условием `if`.
