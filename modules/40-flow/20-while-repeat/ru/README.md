У Lua есть циклы с проверкой до тела и после него. В этом уроке мы сравним `while` и `repeat` и посчитаем число шагов до достижения границы.

Цикл `while` проверяет условие перед каждым проходом. Тело ограничивается словами `do` и `end`.

```lua
local value = 1
while value < 10 do
    value = value * 2
end
print(value) -- 16
```

Умножение выполнится для значений `1`, `2`, `4` и `8`. После получения `16` проверка вернёт `false`. Если условие сразу ложно, тело не выполняется ни разу.

Цикл `repeat` сначала выполняет тело, затем проверяет условие после `until`. Он завершается, когда условие становится истинным. Дополнительный `end` здесь не нужен.

```lua
local value = 5
repeat
    value = value - 1
until value <= 7
print(value) -- 4
```

Условие `value <= 7` было истинным ещё до цикла, но тело всё равно выполнилось. `repeat` всегда проходит тело хотя бы один раз. Локальные переменные тела видны в условии `until`, поскольку условие входит в ту же область видимости.

```lua
local count = 0
repeat
    count = count + 1
    local square = count * count
until square > 10
print(count) -- 4
```

Выбирайте форму по моменту проверки. Когда работа не нужна для уже готового результата, подходит `while`. Когда сначала нужна попытка и затем оценка её результата, подходит `repeat`. В обоих случаях состояние должно меняться так, чтобы цикл мог закончиться.
