В этом уроке мы изучим цикл `while` в Lua. Разберём проверку условия и изменение состояния на каждом шаге. Научимся вычислять число повторений до достижения заданной границы.

Цикл `while` повторяет инструкции, пока условие истинно. Он проверяет условие перед каждым проходом, поэтому может не выполнить тело ни разу. Тело ограничивается словами `do` и `end`.

Предположим, мы увеличиваем ёмкость буфера удвоениями, пока она не вместит десять элементов. Начнём с одного элемента и будем удваивать значение до достижения границы.

```lua
local value = 1
while value < 10 do
    value = value * 2
end
print(value) -- 16
```

Умножение выполнится для значений `1`, `2`, `4` и `8`. После получения `16` проверка вернёт `false`. Если условие сразу ложно, тело не выполняется ни разу.

## Проверка после тела

Если хотя бы одна попытка нужна при любом входе, подходит цикл `repeat`. В качестве сравнения с `while` разберём эту форму цикла. Она сначала выполняет тело, затем проверяет условие после `until`. Цикл завершается, когда условие становится истинным. Дополнительный `end` здесь не нужен.

Уменьшим число хотя бы один раз и затем проверим, стало ли оно не больше семи.

```lua
local value = 5
repeat
    value = value - 1
until value <= 7
print(value) -- 4
```

Условие `value <= 7` было истинным ещё до цикла, но тело всё равно выполнилось. `repeat` всегда проходит тело хотя бы один раз. Локальные переменные тела видны в условии `until`, поскольку условие входит в ту же область видимости.

Для примера найдём первое положительное целое число, квадрат которого больше десяти. Переменную `square` вычислим внутри тела и проверим после него.

```lua
local count = 0
repeat
    count = count + 1
    local square = count * count
until square > 10
print(count) -- 4
```

После четырёх проходов `count` равно `4`, а `square` равно `16`. Условие завершает цикл.

Выбор формы зависит от момента проверки. Когда работа не нужна для уже готового результата, подходит `while`. Когда сначала нужна попытка и затем оценка её результата, подходит `repeat`. В обоих случаях состояние должно меняться так, чтобы цикл мог закончиться.
