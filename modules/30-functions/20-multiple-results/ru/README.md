В этом уроке мы изучим несколько возвращаемых значений в Lua. Разберём получение результатов и их передачу другому вызову. Научимся сохранять нужные результаты функции при присваивании.

Функция Lua может вернуть несколько отдельных значений без создания коллекции. Это удобно, когда один расчёт даёт несколько связанных ответов, например частное и остаток от деления.

Рассчитаем, сколько полных групп по пять предметов можно составить из семнадцати предметов и сколько останется. Функция `divide` вернёт оба ответа одним вызовом.

```lua
local function divide(value, divisor)
    return value // divisor, value % divisor
end

local quotient, remainder = divide(17, 5)
print(quotient) -- 3
print(remainder) -- 2
```

В примере `quotient` получает `3`, а `remainder` получает `2`. Множественное присваивание принимает результаты слева направо. Если переменных больше, оставшиеся получают `nil`. Если переменная одна, она получает первый результат.

Выведем результаты `divide` тремя способами, чтобы сравнить передачу всех результатов с передачей первого. Несколько значений сохраняются, когда вызов стоит последним в списке выражений. Это относится к аргументам другого вызова и к `return`.

```lua
local function divide(value, divisor)
    return value // divisor, value % divisor
end

print(divide(17, 5))
print(divide(17, 5), 'done')
print((divide(17, 5)))
```

`print` разделяет несколько аргументов табуляцией.

```text
3       2
3       done
3
```

В первом вызове `print` получает оба результата. Во втором после вызова есть ещё выражение, поэтому от `divide` остаётся только первый результат. Скобки вокруг самого вызова тоже сворачивают результаты до одного.

Запись `return another_function()` передаёт все результаты другой функции. Запись `return (another_function())` передаёт только первый. Это различие понадобится для передачи ошибок вместе с пояснением и для работы с защищённым вызовом `pcall`.
