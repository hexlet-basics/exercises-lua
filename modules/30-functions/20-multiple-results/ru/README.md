Функция Lua может вернуть несколько отдельных значений без создания коллекции. В этом уроке мы получим два результата и разберём, когда сохраняется только первый из них.

```lua
local function divide(value, divisor)
    return value // divisor, value % divisor
end

local quotient, remainder = divide(17, 5)
print(quotient) -- 3
print(remainder) -- 2
```

Множественное присваивание принимает результаты слева направо. Если переменных больше, оставшиеся получают `nil`. Если переменная одна, она получает первый результат.

Несколько значений сохраняются, когда вызов стоит последним в списке выражений. Это относится к аргументам другого вызова и к `return`.

```lua
local function divide(value, divisor)
    return value // divisor, value % divisor
end

print(divide(17, 5)) -- 3 and 2, separated by a tab
print(divide(17, 5), 'done') -- 3 and done
print((divide(17, 5))) -- 3
```

В первом вызове `print` получает оба результата. Во втором после вызова есть ещё выражение, поэтому от `divide` остаётся только первый результат. Скобки вокруг самого вызова тоже сворачивают результаты до одного.

Запись `return another_function()` передаёт все результаты другой функции. Запись `return (another_function())` передаёт только первый. Это различие понадобится для передачи ошибок вместе с пояснением и для работы с защищённым вызовом `pcall`.
