Функция Lua сохраняет доступ к локальным переменным внешней функции после завершения её вызова. В этом уроке мы используем замыкание, чтобы создать независимые счётчики.

```lua
local function make_adder(step)
    return function(value)
        return value + step
    end
end

local add_five = make_adder(5)
print(add_five(10)) -- 15
```

Внутренняя функция использует параметр `step` внешнего вызова. Значение остаётся доступным, хотя `make_adder` уже завершилась. Такую функцию вместе с доступными ей внешними локальными переменными называют замыканием.

Захваченная переменная может меняться. Каждый вызов возвращённой функции будет обращаться к тому же состоянию.

```lua
local function make_counter()
    local count = 0
    return function()
        count = count + 1
        return count
    end
end

local counter = make_counter()
print(counter()) -- 1
print(counter()) -- 2
```

Новый вызов `make_counter()` создаст новую локальную переменную `count` и новую функцию, которая работает с ней. Поэтому два независимо созданных счётчика не влияют друг на друга.

Состояние счётчика находится в локальной области внешнего вызова. Делать его глобальным не требуется. В следующем модуле мы подробнее разберём блоки и затенение локальных имён, которые определяют, какую именно переменную захватывает функция.
