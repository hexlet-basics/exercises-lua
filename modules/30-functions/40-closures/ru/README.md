В этом уроке мы изучим замыкания Lua. Разберём захват локальных переменных и создание функций с состоянием. Научимся писать независимые счётчики.

Вложенная функция может обращаться к локальным переменным внешнего блока. Она сохраняет этот доступ даже после завершения внешнего вызова. Функцию вместе с доступными ей внешними локальными переменными называют замыканием. Переменную, к которой функция сохранила доступ, называют захваченной.

Предположим, программе нужны операции прибавления с разными шагами. Функция `make_adder` получит шаг и вернёт готовую операцию. Её параметр `step` будет доступен внутренней функции после возврата из `make_adder`.

```lua
local function make_adder(step)
    return function(value)
        return value + step
    end
end

local add_five = make_adder(5)
print(add_five(10)) -- 15
```

Вызов `make_adder(5)` создаёт локальный параметр `step` со значением `5`. Возвращённая функция использует именно эту переменную, поэтому `add_five(10)` возвращает `15`.

Захваченная переменная может меняться. Например, счётчику нужно помнить число предыдущих вызовов. Создадим локальную `count` внутри `make_counter`, а увеличивать её будет возвращённая функция. Каждый вызов этой функции будет обращаться к тому же состоянию.

```lua
local function make_counter()
    local count = 0
    return function()
        count = count + 1
        return count
    end
end

local counter = make_counter()
print(counter()) -- 1
print(counter()) -- 2
```

Первый вызов `counter()` меняет `count` с `0` на `1`, второй с `1` на `2`.

Новый вызов `make_counter()` создаст новую локальную переменную `count` и новую функцию, которая работает с ней. Поэтому два независимо созданных счётчика не влияют друг на друга.

```lua
local first = make_counter()
local second = make_counter()
print(first()) -- 1
print(first()) -- 2
print(second()) -- 1
```

У `first` и `second` свои переменные `count`, поэтому вызовы первого счётчика не увеличивают второй. Состояние каждого счётчика находится в локальной области своего внешнего вызова. Делать его глобальным не требуется.

Замыкание сохраняет доступ к той переменной, которую видело в месте своего определения. Создание другого локального имени с тем же написанием позже не переключает уже созданную функцию на новую переменную.

```lua
local value = 10
local function show()
    return value
end
local value = 99
print(show()) -- 10
```

Здесь `show` сохраняет доступ к первой переменной `value`. Повторное объявление создаёт другую локальную переменную, с которой функция не связана.
