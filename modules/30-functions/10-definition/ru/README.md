Определение функции Lua завершается словом `end`. В этом уроке мы объявим локальную функцию, передадим ей параметры и вернём вычисленный результат.

```lua
local function rectangle_area(width, height)
    return width * height
end

print(rectangle_area(3, 4)) -- 12
```

Параметры создаются как локальные имена при каждом вызове. `return` завершает текущий вызов и передаёт значение вызывающему коду. Если функция закончилась без `return`, она не возвращает результатов.

Слово `local` ограничивает доступность имени функции текущим блоком. Форма `local function` также позволяет обращаться к этой функции из её собственного тела, что нужно для рекурсии.

Количество аргументов Lua не сверяет с количеством параметров. Недостающие параметры получают `nil`, а лишние аргументы обычной функции отбрасываются. Например, `rectangle_area(3)` приведёт к ошибке умножения числа на `nil`. Если параметр необязателен, значение по умолчанию нужно обработать в теле самостоятельно.

Файл Lua выполняется как отдельный блок кода и тоже может вернуть результат. В заготовках упражнений после объявления функции стоит готовая строка возврата самой функции, например `return total_price`. Она передаёт тестам саму функцию, чтобы её можно было вызвать с разными аргументами. Круглых скобок в этой строке нет, поэтому вызов здесь не происходит.

В заданиях дописывайте тело указанной функции. Готовую строку возврата из файла сохраняйте. Подключение файлов через `require` разберём в последнем модуле.
