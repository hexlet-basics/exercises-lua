В этом уроке мы изучим локальные функции Lua. Разберём объявление функции, передачу аргументов и возврат результата. Научимся выделять повторяющееся вычисление в функцию.

Функция объединяет инструкции для одной задачи. Параметры задают входные данные, а результат вызова можно использовать в другом вычислении. В Lua определение функции завершается словом `end`.

Предположим, программа рассчитывает площадь нескольких прямоугольных деталей. Выделим умножение ширины на высоту в функцию `rectangle_area`, чтобы повторять расчёт с разными размерами.

```lua
local function rectangle_area(width, height)
    return width * height
end

print(rectangle_area(3, 4)) -- 12
```

Вызов `rectangle_area(3, 4)` передаёт `3` в `width` и `4` в `height`, поэтому результат равен `12`. Параметры создаются как локальные имена при каждом вызове. `return` завершает текущий вызов и передаёт значение вызывающему коду. Если функция закончилась без `return`, она не возвращает результатов.

Слово `local` ограничивает доступность имени функции текущим блоком. Форма `local function` также позволяет обращаться к этой функции из её собственного тела, что нужно для рекурсии.

Количество аргументов Lua не сверяет с количеством параметров. Недостающие параметры получают `nil`, а лишние аргументы обычной функции отбрасываются. Например, в ошибочном варианте файла _index.lua_ передана только ширина.

<!-- lint-code-blocks: skip — вызов без аргумента height приводит к ошибке умножения -->

```text
local function rectangle_area(width, height)
    return width * height
end
print(rectangle_area(3))
```

Параметр `height` получает `nil`, поэтому умножение останавливает выполнение с ошибкой.

```text
lua: index.lua:2: attempt to perform arithmetic on a nil value (local 'height')
```

Если параметр необязателен, значение по умолчанию нужно обработать в теле самостоятельно.

Файл Lua выполняется как отдельный блок кода и тоже может вернуть результат. В заготовках упражнений после объявления функции стоит готовая строка возврата самой функции, например `return total_price`. Она передаёт тестам саму функцию, чтобы её можно было вызвать с разными аргументами. Круглых скобок в этой строке нет, поэтому вызов здесь не происходит.

В заданиях мы дописываем тело указанной функции и сохраняем готовую строку возврата из файла. Подключение файлов через `require` разберём дальше в курсе.
