В этом уроке мы изучим области видимости локальных переменных Lua. Разберём блоки `do` и `end`, повторные объявления и затенение имён. Научимся сохранять нужное значение при выходе из блока.

Область видимости определяет, где в программе доступно имя переменной. Локальное имя Lua доступно после объявления в своём блоке и во вложенных блоках. Пара `do` и `end` выделяет отдельный блок, чтобы ограничить доступ к временным именам.

Предположим, для промежуточного расчёта нужно удвоить исходное значение. Сохраним результат в переменной `doubled` внутри блока, а исходное `value` оставим доступным после него.

```lua
local value = 10
do
    local doubled = value * 2
    print(doubled) -- 20
end
print(value) -- 10
```

Блок может читать внешнее `value`. Имя `doubled` существует только внутри него. После `end` это локальное имя недоступно.

Если объявить внутри другое локальное имя `value`, оно затенит внешнее. Изменение внутренней переменной не затронет внешнюю.

```lua
local value = 10
do
    local value = 20
    value = value + 1
    print(value) -- 21
end
print(value) -- 10
```

Без внутреннего `local` присваивание изменило бы уже доступную внешнюю переменную. Если доступного локального объявления нет вовсе, присваивание обращается к глобальному окружению.

Область нового локального имени начинается после его объявления. В записи `local value = value + 1` правая часть использует предыдущее доступное `value`.

```lua
local value = 10
do
    local value = value + 1
    print(value) -- 11
end
print(value) -- 10
```

Если значение нужно после `end`, мы объявляем переменную до блока и присваиваем её внутри.

```lua
local result
do
    local temporary = 20
    result = temporary + 1
end
print(result) -- 21
```

Присваивание `result = temporary + 1` сохраняет `21` во внешней переменной `result`. Её объявление находится до `do`, поэтому значение доступно после `end`. Имя `temporary` объявлено внутри блока и за его пределами недоступно.

Блоки условий и циклов тоже ограничивают доступ к объявленным внутри локальным именам. Эти конструкции разберём дальше.
