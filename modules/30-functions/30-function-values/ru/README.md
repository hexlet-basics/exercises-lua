В этом уроке мы изучим функции как значения в Lua. Разберём сохранение функции в переменной и передачу её через параметр. Научимся применять один порядок действий к разным операциям.

В Lua у функции есть значение, которое можно сохранить или передать другому коду. Выбор вычисления при этом отделён от места его выполнения. Имя функции без скобок обозначает саму функцию, а запись со скобками вызывает её.

Предположим, программа должна удваивать полученные числа. Сохраним функцию `double` в переменной `operation`, через которую будем вызывать выбранное вычисление.

```lua
local function double(value)
    return value * 2
end

local operation = double
print(operation(4)) -- 8
```

Присваивание `operation = double` копирует ссылку на функцию. Скобок после `double` нет, поэтому вычисление пока не выполняется. Позже вызов `operation(4)` запускает ту же функцию.

Если одна и та же последовательность действий нужна для разных вычислений, операцию можно получить через параметр. Функция `apply` ниже принимает выбранную операцию и число. Для примера передадим ей `math.abs`, чтобы получить модуль отрицательного числа.

```lua
local function apply(operation, value)
    return operation(value)
end

print(apply(math.abs, -5)) -- 5
```

`apply` не знает, что именно делает операция. Она отвечает только за вызов с переданным значением. Такой параметр помогает использовать общий порядок действий с разными вычислениями.

Когда операция нужна только в одном месте, ей можно не давать отдельное имя. Для такого случая подходит анонимная функция. Выражение `function(value) return value + 3 end` создаёт функцию без отдельного имени.

В следующем вызове `apply` прибавим к числу `7` значение `3`.

```lua
local function apply(operation, value)
    return operation(value)
end

local result = apply(function(value)
    return value + 3
end, 7)
print(result) -- 10
```

Здесь `apply` вызывает переданную анонимную функцию с аргументом `7` и возвращает `10`.

Если передать `math.abs(-5)`, вызывающий код сначала вычислит результат `5`. Тогда `apply` получит число вместо функции. Это видно в ошибочном варианте файла _index.lua_.

```text
local function apply(operation, value)
    return operation(value)
end
print(apply(math.abs(-5), -5))
```

Попытка вызвать число `5` через параметр `operation` останавливает программу.

```text
lua: index.lua:2: attempt to call a number value (local 'operation')
```

Имя без вызова нужно тогда, когда другая функция должна сама выбрать момент выполнения.
