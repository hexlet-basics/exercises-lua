В этом уроке мы изучим переменные и присваивание в Lua. Сравним локальные и глобальные имена и разберём присваивание нескольких значений. Научимся обновлять переменную и обменивать значения двух переменных.

Переменная связывает имя со значением, которое программа использует в вычислениях. Слово `local` объявляет локальную переменную. Последующее присваивание этому имени заменяет сохранённое значение.

Предположим, к цене товара нужно прибавить стоимость упаковки. Сохраним цену в `price`, затем увеличим её на `5`.

```lua
local price = 30
price = price + 5
print(price) -- 35
```

В правой части `price + 5` используется прежнее значение `30`. После присваивания `price` содержит `35`, и `print` выводит обновлённую цену.

Для изменения уже объявленной переменной `local` не повторяют. Оператор `+=` в Lua отсутствует, поэтому обновление записывается целиком.

Присваивание имени без доступного локального объявления записывает значение в глобальное окружение. Такое имя может затронуть другие части программы. В учебных решениях объявляйте переменные через `local`. Область видимости локальных имён мы отдельно разберём дальше в курсе.

Lua позволяет объявить несколько переменных и присвоить несколько значений одной инструкцией. Все выражения справа вычисляются до записи в переменные слева. Это позволяет обменять значения без временной переменной. Например, поменяем местами значения `left` и `right`.

```lua
local left, right = 10, 20
left, right = right, left
print(left) -- 20
print(right) -- 10
```

Сначала Lua прочитает прежние значения `right` и `left`. Затем запишет `20` в `left` и `10` в `right`. Обычные последовательные присваивания не дали бы такого результата, потому что первое изменило бы значение для второго.

Если справа меньше значений, свободные позиции получают `nil`. Это значение обозначает отсутствие данных. Лишние значения справа отбрасываются.

```lua
local first, second = 1
print(second) -- nil

local only = 1, 2
print(only) -- 1
```

Переменная `second` не получила отдельного значения справа, поэтому содержит `nil`. Для `only` используется первое значение `1`, а второе отбрасывается.

Имена различают регистр и могут содержать латинские буквы, цифры и подчёркивание. Начинать имя с цифры нельзя. В курсе используем имена вида `total_price` и не занимаем ключевые слова вроде `local` или `end`.
