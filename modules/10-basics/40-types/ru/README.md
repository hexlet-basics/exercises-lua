В этом уроке мы изучим типы значений и отсутствие значения в Lua. Разберём проверку типа через `type` и преобразование строк в числа. Научимся отличать число от его текстовой записи и распознавать неудачное преобразование.

Тип в Lua принадлежит значению. Переменная может получить значение другого типа при следующем присваивании. Это важно при чтении текстовых данных, поскольку запись числа в строке ещё не делает её числом.

Сравним число `12` и строку `'12'`, последовательно присвоив их переменной `value`.

```lua
local value = 12
print(type(value)) -- number
value = '12'
print(type(value)) -- string
```

Первый вызов `type` получает число и возвращает `'number'`. После нового присваивания переменная хранит строку, поэтому второй вызов возвращает `'string'`.

Встроенная функция `type` возвращает строку с именем типа. В базовых программах нам понадобятся `number`, `string`, `boolean`, `table`, `function` и `nil`. Остальные типы относятся к более специальным возможностям языка.

Локальная переменная без начального значения содержит `nil`. Точно так же `nil` возвращается из некоторых операций, когда результат отсутствует.

```lua
local missing
print(missing) -- nil
print(type(missing)) -- nil
```

Два вызова `print` выглядят одинаково, но печатают значения разных типов. Первый получает само `nil`, второй получает строку `'nil'`, возвращённую из `type`.

Число и его строковая запись относятся к разным типам. Чтобы явно получить число из строки, вызовите `tonumber`. Например, прочитаем количество товаров из строки `'15'` и прибавим ещё два товара.

```lua
local amount = tonumber('15')
print(amount + 2) -- 17
print(tonumber('hello')) -- nil
```

Переменная `amount` содержит число `15`, поэтому сложение даёт `17`. Текст `'hello'` не задаёт число, и второй вызов `tonumber` возвращает `nil`.

Некорректная запись числа даёт `nil`. С таким результатом нельзя продолжать арифметику без проверки. Проверять его условием научимся дальше в курсе.

Для обратного преобразования есть `tostring`. Например, `tostring(15)` возвращает `'15'`. Lua умеет выполнять некоторые неявные преобразования, но явный вызов показывает намерение программы и позволяет отдельно обработать неудачу.
