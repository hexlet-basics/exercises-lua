В этом уроке мы изучим синтаксис и комментарии Lua. Разберём запись инструкций и сообщения интерпретатора об ошибках. Научимся отключать отладочный вывод и находить незакрытые строки.

Синтаксис задаёт правила записи программы. Если запись нарушает эти правила, интерпретатор останавливается ещё до выполнения инструкций. Комментарии позволяют оставить пояснение в коде или временно исключить инструкцию из выполнения.

Несколько инструкций выполняются по порядку. Перенос строки и отступ помогают читать код, но отступ сам по себе не создаёт блок. Открытый блок обычно завершается словом `end`. Конкретные блоки условий и функций мы разберём дальше.

Однострочный комментарий начинается с `--`. Для нескольких строк можно использовать `--[[` и `]]`.

Предположим, при запуске сценария нужно видеть его начало и завершение. Добавим два сообщения и пояснения к ним.

```lua
-- A short explanation
print('Start')

--[[
This comment occupies
more than one line.
]]
print('Finish')
```

Интерпретатор выполнит два вызова `print` и выведет `Start` и `Finish` на отдельных строках. Текст после `--` и между `--[[` и `]]` на вывод не влияет.

Два дефиса внутри кавычек остаются частью строки. Например, `print('--')` выводит два дефиса.

Скобки и кавычки должны быть парными. Следующий антипример содержит незакрытую строку.

<!-- lint-code-blocks: skip — незакрытая строка вызывает синтаксическую ошибку -->

```text
print('Ready)
```

Интерпретатор остановит разбор и сообщит примерно следующее.

```text
lua: index.lua:1: unfinished string near ''Ready)'
```

Число после имени файла обозначает строку, где интерпретатор обнаружил проблему. Причина может находиться раньше указанного места. В этом случае перед закрывающей скобкой не хватает кавычки. Исправленная запись выглядит как `print('Ready')`.

Lua различает регистр имён. В стандартной библиотеке есть `print`, а `Print` обозначает другое имя. Неверный регистр может привести к ошибке уже при выполнении синтаксически корректной программы.

<!-- lint-code-blocks: skip — неверный регистр имени приводит к вызову nil -->

```text
Print('Ready')
```

Разбор проходит успешно, а при запуске имя `Print` не содержит функции.

```text
lua: index.lua:1: attempt to call a nil value (global 'Print')
```
