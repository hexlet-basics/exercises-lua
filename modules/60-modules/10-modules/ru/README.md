Модуль Lua обычно представляет собой файл, который возвращает значение. В этом уроке мы подключим готовый модуль через `require` и используем его функцию.

Например, файл _pricing.lua_ может вернуть таблицу с функцией.

```lua
local pricing = {}

function pricing.total(price, count)
    return price * count
end

return pricing
```

Запись `function pricing.total(...) ... end` сохраняет функцию в поле `total` таблицы. Функция не получает саму таблицу автоматически. Для такого вызова используем точку и передаём указанные параметры явно.

В другом файле подключим модуль по имени без расширения.

```lua
local pricing = require('pricing')
print(pricing.total(20, 3)) -- 60
```

`require` ищет модуль по настроенным путям. Для файлов Lua они описаны в `package.path`. Обычная конфигурация включает шаблон `./?.lua`, который ищет файл в текущем рабочем каталоге программы. Расположение файла, который вызывает `require`, на поиск не влияет. Если модуль не найден, сообщение показывает проверенные пути.

Возвращённое значение кешируется в `package.loaded`. Повторный `require` того же имени обычно возвращает уже загруженное значение. Поэтому таблица модуля может разделять состояние между вызывающими частями программы. Имя модуля указывается строкой, а не путём с расширением.

Строка `return function_name` возвращает из файла одну функцию. Таблица экспорта позволяет вернуть несколько связанных операций под именами. В упражнении готовый модуль уже находится в каталоге упражнения, из которого запускается проверка. Устанавливать пакеты не требуется. Обычно `require` размещают в начале файла. Вызов внутри функции тоже использует кеш и не загружает модуль заново.
