В этом уроке мы изучим подключение модулей через `require`. Разберём создание файла модуля и использование возвращённой им таблицы. Научимся подключать связанные функции в другом файле программы.

Когда одна операция нужна в нескольких частях программы, её можно вынести в отдельный файл. Такой файл называют модулем. Он возвращает значение, через которое остальной код получает доступ к его возможностям. Обычно этим значением служит таблица со связанными функциями.

Предположим, программа рассчитывает стоимость товаров для корзины и для чека. Чтобы хранить расчёт в одном месте, поместим его в файл _pricing.lua_. Таблица `pricing` будет содержать функцию `total`.

```lua
local pricing = {}

function pricing.total(price, count)
    return price * count
end

return pricing
```

Запись `function pricing.total(...) ... end` сохраняет функцию в поле `total` таблицы. Функция принимает цену и количество товаров. Саму таблицу она автоматически не получает. Для вызова используем точку и передаём указанные параметры явно.

Файл _index.lua_ находится в том же каталоге. Он подключает расчёт по имени модуля без расширения и вызывает его функцию.

```lua
local pricing = require('pricing')
print(pricing.total(20, 3)) -- 60
```

При запуске _index.lua_ из каталога этих файлов `require('pricing')` находит _pricing.lua_, выполняет его и получает возвращённую таблицу. Переменная `pricing` в _index.lua_ хранит эту таблицу. Вызов `pricing.total(20, 3)` вычисляет стоимость трёх товаров по цене `20`.

## Поиск и повторное подключение

`require` ищет файлы Lua по шаблонам из `package.path`. Обычная конфигурация включает `./?.lua`, который ищет файл в текущем рабочем каталоге программы. Расположение файла, который вызывает `require`, на поиск не влияет. Например, для имени `'pricing'` вместо `?` подставляется `pricing`, и получается путь _./pricing.lua_. Если модуль не найден, сообщение показывает проверенные пути.

Возвращённое значение кешируется в `package.loaded`. Повторный `require` того же имени обычно возвращает уже загруженное значение.

```lua
local first = require('pricing')
local second = require('pricing')
print(first == second) -- true
```

Обе переменные ссылаются на одну таблицу модуля. Поэтому модуль может разделять состояние между вызывающими частями программы.

Строка `return function_name` возвращает из файла одну функцию. Таблица экспорта позволяет вернуть несколько связанных операций под именами. Обычно `require` размещают в начале файла. Вызов внутри функции тоже использует кеш и не загружает модуль заново.
