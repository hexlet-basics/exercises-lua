В этом уроке мы изучим вложенные таблицы. Разберём обращение к полям записей внутри последовательности и изменение общих данных. Научимся искать запись по значению её поля.

Значением поля или элемента может быть другая таблица. Благодаря этому последовательность хранит объекты с несколькими свойствами. Внешняя таблица задаёт порядок, а внутренние записи содержат поля каждого объекта.

Предположим, каталог товаров должен хранить название и цену каждого товара. Два независимых набора названий и цен пришлось бы согласовывать по индексам. Последовательность записей хранит связанные свойства вместе.

```lua
local products = {
    { name = 'Tea', price = 250 },
    { name = 'Coffee', price = 400 },
}
print(products[1].name) -- Tea
print(products[2].price) -- 400
```

Доступ `products[1].name` сначала находит первую запись, затем её поле. В примере первая запись описывает чай, вторая описывает кофе.

Обход `ipairs` выдаёт ссылки на внутренние таблицы. Через переменную `product` можно прочитать имя каждого товара.

```lua
local products = {
    { name = 'Tea', price = 250 },
    { name = 'Coffee', price = 400 },
}
for _, product in ipairs(products) do
    print(product.name)
end
```

Получаем названия в порядке последовательности.

```text
Tea
Coffee
```

Изменение поля через переменную цикла меняет запись в исходной последовательности.

```lua
local products = { { name = 'Tea', price = 250 } }
for _, product in ipairs(products) do
    product.price = product.price + 50
end
print(products[1].price) -- 300
```

В переменной `product` находится ссылка на первую запись из `products`. Присваивание увеличивает её поле `price` с `250` до `300`, поэтому чтение того же поля через `products[1]` показывает новую цену.

Поверхностная копия внешней таблицы тоже сохраняет ссылки на внутренние таблицы. Для независимого изменения вложенных данных нужно создавать копии и на соответствующем внутреннем уровне.

```lua
local product = { name = 'Tea', details = { price = 250 } }
local copy = {}
for key, value in pairs(product) do
    copy[key] = value
end
copy.details.price = 300
print(product.details.price) -- 300
print(copy.details == product.details) -- true
```

Цикл создал отдельную внешнюю таблицу `copy`, но в её поле `details` перенёс ссылку на прежнюю внутреннюю таблицу. Оба пути `copy.details` и `product.details` ведут к одним данным, поэтому изменение цены через копию видно в исходном товаре. Сравнение этих ссылок возвращает `true`.

Для поиска удобно вернуть подходящую запись сразу из цикла. Если обход завершился без совпадения, функция возвращает `nil`. Например, найдём товар с заданной ценой.

```lua
local function find_by_price(products, expected_price)
    for _, product in ipairs(products) do
        if product.price == expected_price then
            return product
        end
    end
    return nil
end

local products = {
    { name = 'Tea', price = 250 },
    { name = 'Coffee', price = 400 },
}
print(find_by_price(products, 400).name) -- Coffee
print(find_by_price(products, 100)) -- nil
```

Ранний возврат завершает и цикл, и функцию. Явный `return nil` показывает соглашение для отсутствующего результата. Получатель должен проверить его до обращения к полям.

При нескольких совпадениях такой поиск вернёт первую подходящую запись в порядке последовательности, и вызывающий код может на это рассчитывать.
