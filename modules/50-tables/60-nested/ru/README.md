Элемент таблицы может быть другой таблицей. В этом уроке мы соединим последовательность с записями и найдём объект по значению поля.

```lua
local products = {
    { name = 'Tea', price = 250 },
    { name = 'Coffee', price = 400 },
}
print(products[1].name) -- Tea
print(products[2].price) -- 400
```

Внешняя таблица является последовательностью. Каждый её элемент содержит запись с полями `name` и `price`. Доступ `products[1].name` сначала находит первую запись, затем её поле.

Обход `ipairs` выдаёт сами ссылки на внутренние таблицы.

```lua
local products = {
    { name = 'Tea', price = 250 },
    { name = 'Coffee', price = 400 },
}
for _, product in ipairs(products) do
    print(product.name)
end
```

Изменение `product.price` внутри цикла изменило бы запись в исходном списке. Это следствие ссылочной семантики таблиц, которую мы разбирали раньше.

Для поиска удобно вернуть подходящую запись сразу из цикла. Если обход завершился без совпадения, функция может вернуть `nil`.

```lua
local function find_by_price(products, expected_price)
    for _, product in ipairs(products) do
        if product.price == expected_price then
            return product
        end
    end
    return nil
end
```

Ранний возврат завершает и цикл, и функцию. Явный `return nil` показывает соглашение для отсутствующего результата. Получатель должен проверить его до обращения к полям.

При нескольких совпадениях такой поиск вернёт первое по порядку последовательности. Это поведение нужно отразить в условии задания, чтобы вызывающий код мог на него рассчитывать.
