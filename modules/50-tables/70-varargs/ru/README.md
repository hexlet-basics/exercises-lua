Функция Lua может принять переменное число аргументов через `...`. В этом уроке мы сохраним такие аргументы в таблице и передадим их другому вызову с учётом `nil`.

```lua
local function maximum(...)
    return math.max(...)
end
print(maximum(3, 9, 4)) -- 9
```

Три точки в списке параметров разрешают использовать `...` в теле. На последней позиции списка выражений они передают все аргументы. В другом месте или внутри дополнительных скобок сохраняется только первый, как у вызова с несколькими результатами.

Конструктор `{ ... }` собирает аргументы в таблицу. Если среди них есть `nil`, возникают пропуски. Для сохранения точного количества используется `table.pack`, которая добавляет поле `n`.

```lua
local arguments = table.pack('first', nil, 'third')
print(arguments.n) -- 3
print(arguments[2]) -- nil
```

`ipairs` остановится на второй позиции. Чтобы обработать все переданные позиции, нужен числовой цикл от `1` до `arguments.n`. Функция `select('#', ...)` тоже возвращает количество аргументов, включая `nil`.

```lua
print(select('#', 'first', nil, 'third')) -- 3
```

Для обратного преобразования таблицы в несколько значений используется `table.unpack`. Явные границы сохраняют позиции, которые содержат `nil`.

```lua
local arguments = table.pack('first', nil, 'third')
print(table.unpack(arguments, 1, arguments.n))
```

```text
first   nil     third
```

Без явной конечной границы `table.unpack` использует `#`, что не подходит таблице с пропусками. Используйте пару `table.pack` и `table.unpack(arguments, 1, arguments.n)`, когда важно передать набор аргументов без потерь.
