В этом уроке мы изучим функции с переменным числом аргументов. Разберём сохранение аргументов вместе с их количеством и передачу в другой вызов. Научимся обрабатывать все переданные позиции, включая `nil`.

Некоторые операции принимают заранее неизвестное количество значений. Например, функция `print` выводит столько аргументов, сколько ей передали. Собственная функция получает такие аргументы через параметр с тремя точками `...`. В теле функции три точки обозначают переданные значения.

Собственная функция может передать эти значения готовой функции. Например, найдём максимум среди произвольного количества чисел через `math.max`.

```lua
local function maximum(...)
    return math.max(...)
end
print(maximum(3, 9, 4)) -- 9
```

На последней позиции списка выражений `...` передаёт все аргументы. В другом месте или внутри дополнительных скобок сохраняется только первый, как у вызова с несколькими результатами.

Конструктор `{ ... }` собирает аргументы в таблицу. Если среди них есть `nil`, возникают пропуски и `#` не позволяет узнать точное количество. Функция `table.pack(...)` сохраняет значения в таблице и добавляет поле `n` с количеством аргументов. Числовой цикл с этой границей обработает каждую переданную позицию.

```lua
local function describe(...)
    local arguments = table.pack(...)
    print(arguments.n)
    for index = 1, arguments.n do
        print(index, arguments[index])
    end
end

describe('first', nil, 'third')
```

Числовой цикл проходит все позиции до `arguments.n`.

```text
3
1       first
2       nil
3       third
```

При пустом вызове `describe()` поле `n` равно `0`, и тело цикла не выполняется. Обход через `ipairs` здесь не подходит, потому что он остановится на первом `nil`.

Чтобы передать сохранённые значения другому вызову, используется `table.unpack(arguments, 1, arguments.n)`. Явные границы сохраняют позиции с `nil`.

```lua
local function show(...)
    local arguments = table.pack(...)
    print(table.unpack(arguments, 1, arguments.n))
end

show('first', nil, 'third', nil)
```

В вызов `print` попадут все аргументы, включая последний `nil`.

```text
first   nil     third   nil
```

Без явной конечной границы `table.unpack` использует `#`, что не подходит таблице с пропусками. Пара `table.pack` и `table.unpack` с границей `n` сохраняет число и порядок переданных значений.
