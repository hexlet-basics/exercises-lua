В этом уроке мы изучим сборку таблицы во время обхода данных. Разберём подсчёт повторений по ключам и перенос полей в новую таблицу. Научимся создавать словари с результатами обработки.

Конструктор `{}` создаёт пустую таблицу. Дальше программа может добавлять поля по мере чтения данных. Вычисляемый ключ связывает каждый новый результат с нужным именем.

Предположим, программа получила названия проданных товаров. В исходной последовательности один товар может встречаться несколько раз. Для отчёта нужно собрать словарь, в котором каждому названию соответствует число продаж.

```lua
local sold = { 'Tea', 'Coffee', 'Tea' }
local counts = {}
for _, name in ipairs(sold) do
    counts[name] = (counts[name] or 0) + 1
end
print(counts.Tea) -- 2
print(counts.Coffee) -- 1
```

В начале у `counts` нет полей. Для первого `'Tea'` выражение `counts[name]` возвращает `nil`, поэтому `or 0` выбирает начальное число `0`. После прибавления единицы поле получает `1`. При повторном появлении `'Tea'` программа использует сохранённое число и увеличивает его до `2`.

Входная последовательность остаётся прежней, а словарь `counts` хранит результат. Здесь `or 0` подходит, потому что существующие значения словаря всегда числа. Даже `0` в Lua считается истинным значением.

## Копирование полей

Новую таблицу можно заполнить полями существующей. Это нужно, когда программа хочет менять данные независимо от исходной таблицы. Например, для отдельного заказа подготовим свой вариант цен.

```lua
local prices = { Tea = 250, Coffee = 400 }
local copy = {}
for name, price in pairs(prices) do
    copy[name] = price
end
copy.Tea = 200
print(prices.Tea) -- 250
print(copy.Tea) -- 200
print(copy == prices) -- false
```

Цикл переносит каждую пару в `copy`. Обе таблицы содержат поля с теми же названиями, но изменение поля `copy.Tea` сохраняется только в копии. Такой перенос называют поверхностным копированием. Он копирует значения полей за один уровень. Если значением служит другая таблица, перенесётся ссылка на неё. Этот случай разберём при работе с вложенными таблицами.
