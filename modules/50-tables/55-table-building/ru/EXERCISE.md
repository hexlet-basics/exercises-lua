Допишите `count_items(items)`. Она принимает последовательность строк с названиями товаров и возвращает новую таблицу. В ней каждому названию должно соответствовать количество его появлений в `items`. Для пустой последовательности верните пустую таблицу. Названия сравниваются точно, с учётом регистра. Исходную последовательность не меняйте.

Например, для `{ 'Tea', 'Coffee', 'Tea' }` результат содержит поля `Tea = 2` и `Coffee = 1`.
