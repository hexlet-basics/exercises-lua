Для последовательного обхода таблицы Lua предлагает `ipairs`. В этом уроке мы получим индекс и значение на каждом проходе и накопим сумму элементов.

```lua
local prices = { 10, 20, 30 }
for index, price in ipairs(prices) do
    print(index, price)
end
```

Это общая форма цикла `for ... in ... do ... end`. Функция `ipairs` подготавливает обход целых индексов начиная с `1`. На каждом проходе переменные `index` и `price` получают очередную позицию и значение. `print` разделяет несколько аргументов табуляцией.

Обход останавливается на первом отсутствующем значении, то есть `nil`. Значение `false` остановкой не является. Поэтому `ipairs` подходит для непрерывной последовательности.

```lua
local flags = { true, false, true }
for index, flag in ipairs(flags) do
    print(index, flag)
end
```

Будут обработаны все три элемента. Если удалить вторую позицию через присваивание `nil`, обход завершится до третьей. Именованные поля `ipairs` тоже не перебирает.

Когда индекс не нужен, его обычно называют `_`, показывая читателю, что значение намеренно пропускается.

```lua
local total = 0
for _, price in ipairs({ 10, 20, 30 }) do
    total = total + price
end
print(total) -- 60
```

Переменные цикла локальны его телу. На пустой последовательности тело не выполнится, поэтому начальное значение накопителя определяет результат для пустого входа. Изменять состав списка во время такого обхода в наших задачах не требуется.
