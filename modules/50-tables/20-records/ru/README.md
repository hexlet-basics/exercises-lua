В этом уроке мы изучим именованные поля таблиц и ссылки на таблицы. Разберём чтение и изменение полей с постоянными и вычисляемыми ключами. Научимся различать изменение общей таблицы и создание нового объекта.

Таблица с именованными полями подходит для описания одного объекта. Такую форму данных называют записью. Например, у пользователя есть имя и число баллов, и программа обращается к этим значениям по названиям полей.

```lua
local user = { name = 'Mira', score = 10 }
print(user.name) -- Mira
print(user['score']) -- 10
```

Поле `name` хранит имя пользователя, а `score` хранит его баллы. Запись `user.name` сокращает `user['name']`. Вариант с квадратными скобками позволяет вычислять ключ и использовать строки с пробелами.

```lua
local user = { name = 'Mira', ['display name'] = 'Mira K.' }
local field = 'name'
print(user[field]) -- Mira
print(user['display name']) -- Mira K.
print(user.field) -- nil
```

В `user[field]` ключ берётся из переменной `field`. Обращение `user.field` использует буквальный ключ `'field'`, которого в таблице нет. Таблицы также допускают ключи других типов, кроме `nil` и NaN, нечислового значения вроде результата `0 / 0`. Числовой ключ `1` и строковый ключ `'1'` различаются.

Присваивание таблицы копирует ссылку на неё. Поэтому две переменные могут обозначать один изменяемый объект. Допустим, мы сохранили пользователя под вторым именем и изменили через него поле.

```lua
local user = { name = 'Mira' }
local same_user = user
same_user.name = 'Ada'
print(user.name) -- Ada
print(same_user == user) -- true
```

Изменение через `same_user` видно и через `user`, потому что обе переменные ссылаются на одну таблицу. Сравнение `==` для обычных таблиц проверяет идентичность. Две отдельно созданные таблицы с одинаковыми полями различаются.

```lua
print({ name = 'Ada' } == { name = 'Ada' }) -- false
```

Функция тоже получает ссылку. Если она меняет поле аргумента, вызывающий код увидит изменение. Для независимого изменения нужна новая таблица с перенесёнными полями. Сборку и копирование таблиц разберём дальше по курсу.
