Таблица Lua может хранить значения под строковыми ключами. В этом уроке мы обратимся к полям записи и проверим, что происходит при присваивании таблицы другой переменной.

```lua
local user = { name = 'Mira', score = 10 }
print(user.name) -- Mira
print(user['score']) -- 10
```

Запись `user.name` сокращает `user['name']`. Вариант с квадратными скобками позволяет вычислять ключ и использовать строки с пробелами.

```lua
local user = { name = 'Mira', ['display name'] = 'Mira K.' }
local field = 'name'
print(user[field]) -- Mira
print(user['display name']) -- Mira K.
```

`user.field` обратился бы к буквальному ключу `'field'`. Его в примере нет. Таблицы также допускают ключи других типов, кроме `nil` и числового NaN. Числовой ключ `1` и строковый ключ `'1'` различаются.

Присваивание таблицы копирует ссылку на неё. Две переменные могут обозначать один изменяемый объект.

```lua
local user = { name = 'Mira' }
local same_user = user
same_user.name = 'Ada'
print(user.name) -- Ada
print(same_user == user) -- true
```

Сравнение `==` для обычных таблиц проверяет идентичность. Две отдельно созданные таблицы с одинаковыми полями различаются.

```lua
print({ name = 'Ada' } == { name = 'Ada' }) -- false
```

Функция тоже получает ссылку. Если она меняет поле аргумента, вызывающий код увидит изменение. Когда изменение не требуется, нужно отдельно создать копию подходящей глубины.
