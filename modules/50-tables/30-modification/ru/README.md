В этом уроке мы изучим изменение и сортировку последовательностей. Разберём вставку и удаление элементов с сохранением непрерывных индексов. Научимся упорядочивать данные и собирать их в строку.

При вставке в середину последовательности нужно освободить позицию для нового элемента. При удалении нужно сдвинуть оставшиеся элементы, чтобы не появились пропуски. Эти действия выполняют функции стандартной библиотеки `table`.

Предположим, мы изменяем очередь участников. Добавим Leo в конец и удалим первого участника Mira.

```lua
local names = { 'Mira', 'Ada' }
table.insert(names, 'Leo')
local removed = table.remove(names, 1)
print(removed) -- Mira
print(names[1]) -- Ada
print(names[2]) -- Leo
```

`table.insert(items, value)` добавляет значение в конец. Форма `table.insert(items, position, value)` вставляет его в указанную позицию и сдвигает следующие элементы. `table.remove(items, position)` удаляет элемент, сдвигает последующие и возвращает удалённое значение. Если позиция не задана, удаляется последний элемент.

Присваивание `items[index] = nil` оставляет пропуск. Для удаления из середины последовательности нужна `table.remove`.

Для вывода участников по алфавиту можно изменить порядок через `table.sort`. Она сортирует саму таблицу, используя сравнение `<` по умолчанию.

```lua
local names = { 'Mira', 'Ada', 'Leo' }
table.sort(names)
print(table.concat(names, ', ')) -- Ada, Leo, Mira
```

`table.concat` соединяет элементы с разделителем и возвращает строку. Она подходит для последовательностей строк и чисел. В примере между соседними именами стоят запятая и пробел.

Для своего порядка функция сравнения передаётся вторым аргументом `table.sort`. Она должна вернуть `true`, когда первый элемент должен стоять раньше второго. Для равных элементов функция возвращает `false`, поэтому в таком сравнении используют `<` или `>` без `=`. Например, баллы можно расположить по убыванию.

```lua
local scores = { 3, 8, 5 }
table.sort(scores, function(left, right)
    return left > right
end)
print(table.concat(scores, ', ')) -- 8, 5, 3
```

Сравнение `left > right` ставит большее число раньше меньшего. Поэтому первой оказывается оценка `8`, затем `5` и `3`. `table.concat` показывает уже изменённый порядок элементов `scores`.

Все эти операции рассчитаны на последовательности без пропусков. Для таблиц с произвольными ключами потребуются другие способы обхода.
