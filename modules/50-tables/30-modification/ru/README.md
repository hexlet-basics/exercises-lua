Для последовательностей стандартная библиотека предлагает операции вставки, удаления и сортировки. В этом уроке мы изменим список, сохранив непрерывные индексы, и соберём его в строку.

```lua
local names = { 'Mira', 'Ada' }
table.insert(names, 'Leo')
local removed = table.remove(names, 1)
print(removed) -- Mira
print(names[1]) -- Ada
```

`table.insert(list, value)` добавляет значение в конец. Форма `table.insert(list, position, value)` вставляет его в указанную позицию и сдвигает следующие элементы. `table.remove(list, position)` удаляет элемент, сдвигает последующие и возвращает удалённое значение. Если позиция не задана, удаляется последний элемент.

Присваивание `list[index] = nil` не сдвигает элементы. Поэтому для удаления из середины последовательности используйте `table.remove`.

`table.sort` меняет порядок элементов в самой таблице. По умолчанию используется сравнение `<`.

```lua
local names = { 'Mira', 'Ada', 'Leo' }
table.sort(names)
print(table.concat(names, ', ')) -- Ada, Leo, Mira
```

`table.concat` соединяет элементы с разделителем и возвращает строку. Она подходит для последовательностей строк и чисел.

Для своего порядка передайте функцию сравнения вторым аргументом `table.sort`. Она должна вернуть `true`, когда первый элемент должен стоять раньше второго. Для равных элементов функция возвращает `false`, поэтому в таком сравнении используют `<` или `>` без `=`.

```lua
local scores = { 3, 8, 5 }
table.sort(scores, function(left, right)
    return left > right
end)
print(table.concat(scores, ', ')) -- 8, 5, 3
```

Все эти операции рассчитаны на последовательности без пропусков. Размер словаря с произвольными ключами через них не определяют.
