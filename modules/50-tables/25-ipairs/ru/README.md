В этом уроке мы изучим обход последовательностей через `ipairs`. Разберём получение индекса и значения в общей форме цикла `for`. Научимся обрабатывать элементы по порядку и накапливать результат.

Числовой цикл обращается к элементам через индекс. Когда нужна вся последовательность, `ipairs` подготавливает обход целых индексов начиная с `1` и выдаёт индекс вместе со значением. Переменные цикла локальны его телу.

Предположим, программа выводит цены с их порядковыми номерами. Общая форма цикла `for ... in ... do ... end` позволяет получить обе части на каждом проходе.

```lua
local prices = { 10, 20, 30 }
for index, price in ipairs(prices) do
    print(index, price)
end
```

При запуске получаем такие строки. `print` разделяет несколько аргументов табуляцией.

```text
1       10
2       20
3       30
```

Переменные `index` и `price` получают очередную позицию и цену. Обход останавливается на первом отсутствующем значении, то есть `nil`. Значение `false` остановкой не является.

```lua
local flags = { true, false, true }
for index, flag in ipairs(flags) do
    print(index, flag)
end
```

В вывод попадут все элементы последовательности.

```text
1       true
2       false
3       true
```

Если удалить вторую позицию через присваивание `nil`, обход остановится на ней и третий элемент не обработает.

```lua
local flags = { true, false, true }
flags[2] = nil
for index, flag in ipairs(flags) do
    print(index, flag) -- 1 true
end
```

Именованные поля `ipairs` тоже не перебирает. Для непрерывной последовательности она позволяет обработать все элементы в порядке индексов.

Когда индекс не нужен, его обычно называют `_`, показывая читателю, что значение намеренно пропускается. Для общей стоимости цен понадобится только очередная цена.

```lua
local total = 0
for _, price in ipairs({ 10, 20, 30 }) do
    total = total + price
end
print(total) -- 60
```

На пустой последовательности тело не выполнится, поэтому начальное значение `total` определяет результат для пустого входа. Изменять состав последовательности во время такого обхода в наших задачах не требуется.
