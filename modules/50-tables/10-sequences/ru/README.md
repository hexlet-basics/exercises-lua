В этом уроке мы изучим таблицы и последовательности Lua. Разберём обращение к элементам по индексу и вычисление длины. Научимся хранить упорядоченные данные без пропусков.

Таблица связывает ключи со значениями. Для упорядоченных данных ключами служат целые индексы начиная с `1`. Таблицу с непрерывными индексами от `1` до некоторого `n` называют последовательностью. Каждый индекс указывает на отдельный элемент.

Предположим, программа хранит цвета в порядке их выбора. Последовательность позволяет получить первый и последний цвета по их позициям.

```lua
local colors = { 'red', 'green', 'blue' }
print(colors[1]) -- red
print(colors[3]) -- blue
print(#colors) -- 3
```

Элементы конструктора без явно указанных ключей получают целые индексы начиная с `1`. Оператор `#` возвращает длину последовательности. У пустой таблицы `{}` она равна `0`.

Индекс `0` в примере не создаётся. Чтение отсутствующего элемента возвращает `nil`.

```lua
local colors = { 'red', 'green', 'blue' }
print(colors[0]) -- nil
print(colors[4]) -- nil
```

Значение `nil` в таблице означает отсутствие элемента. Присваивание `colors[2] = nil` удалит вторую позицию, оставив пропуск перед третьей.

```lua
local colors = { 'red', 'green', 'blue' }
colors[2] = nil
print(colors[2]) -- nil
print(colors[3]) -- blue
```

Таблица с таким пропуском уже не является последовательностью. На ней `#` может вернуть одну из нескольких границ, поэтому использовать его как количество элементов нельзя. В задачах на последовательности мы поддерживаем непрерывные индексы и не храним `nil` среди элементов.

Значения `false`, `0` и пустая строка остаются существующими элементами.

```lua
local values = { false, 0, '' }
print(#values) -- 3
print(values[1]) -- false
```

Оператор `#` работает и со строками, но измеряет их в байтах. Для таблиц его смысл определяется структурой целых индексов.
