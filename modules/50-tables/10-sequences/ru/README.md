В Lua одна структура таблицы служит и списком, и набором именованных полей. В этом уроке мы создадим последовательность и разберём её индексы и длину.

```lua
local colors = { 'red', 'green', 'blue' }
print(colors[1]) -- red
print(colors[3]) -- blue
print(#colors) -- 3
```

Элементы конструктора без явно указанных ключей получают целые индексы начиная с `1`. Индекс `0` здесь не создаётся. Чтение отсутствующего элемента возвращает `nil`.

```lua
local colors = { 'red', 'green', 'blue' }
print(colors[0]) -- nil
print(colors[4]) -- nil
```

Таблицу с непрерывными целыми индексами от `1` до некоторого `n` называют последовательностью. Для неё `#` возвращает количество элементов. У пустой таблицы `{}` длина равна `0`.

Значение `nil` в таблице означает отсутствие элемента. Присваивание `colors[2] = nil` удалит вторую позицию, оставив пропуск перед третьей. Таблица с пропусками уже не является последовательностью. На такой таблице `#` может вернуть одну из нескольких границ, поэтому использовать его как количество элементов нельзя.

В задачах на списки мы будем поддерживать непрерывную последовательность и не хранить `nil` среди её элементов. Значения `false`, `0` и пустая строка при этом остаются обычными существующими элементами.

Оператор `#` работает и со строками, но измеряет их в байтах. Для таблиц его смысл определяется именно структурой целых индексов.
