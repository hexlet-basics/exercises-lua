У записи с именованными полями нет последовательных позиций для `ipairs`. В этом уроке мы обойдём все поля через `pairs` и посчитаем сумму значений словаря.

```lua
local stock = { apples = 3, pears = 2 }
for name, count in pairs(stock) do
    print(name, count)
end
```

`pairs` выдаёт ключ и значение каждого существующего поля обычной таблицы. Порядок обхода не гарантируется. Его нельзя выводить из порядка записи полей в конструкторе или порядка добавления.

Для суммы порядок не важен.

```lua
local stock = { apples = 3, pears = 2 }
local total = 0
for _, count in pairs(stock) do
    total = total + count
end
print(total) -- 5
```

Если нужен упорядоченный вывод, сначала можно собрать строковые ключи в последовательность, отсортировать её и затем прочитать значения по этим ключам.

```lua
local stock = { pears = 2, apples = 3 }
local names = {}
for name in pairs(stock) do
    table.insert(names, name)
end
table.sort(names)
for _, name in ipairs(names) do
    print(name, stock[name])
end
```

Обход отсортированных строковых ключей через `ipairs` задаёт явный порядок вывода.

Присваивание `stock.apples = nil` удаляет поле. После этого его не будет в обходе. Добавление нового поля во время обхода делает поведение `pairs` неопределённым. Изменять и удалять существующие поля можно. В наших задачах изменение набора данных и обход выполняются отдельными шагами.

Оператор `#` для словаря не считает именованные поля. Если требуется количество таких полей, увеличивайте отдельный счётчик при обходе.
