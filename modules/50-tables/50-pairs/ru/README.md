В этом уроке мы изучим обход таблиц через `pairs`. Сравним обход произвольных ключей с обходом последовательности через `ipairs`. Научимся обрабатывать словарь и задавать порядок вывода его данных.

Когда ключами служат названия товаров, непрерывных числовых позиций для `ipairs` нет. Такую таблицу соответствий называют словарём. В записи поля описывают свойства одного объекта, а в словаре каждое поле связывает ключ с отдельным значением. Обе формы используют обычные таблицы Lua. Для обхода словаря `pairs` выдаёт ключ и значение каждого существующего поля таблицы.

Предположим, программа хранит остатки товаров. Название служит ключом, количество служит значением. Для обработки всех остатков используем `pairs`.

```lua
local stock = { apples = 3, pears = 2 }
for name, count in pairs(stock) do
    print(name, count)
end
```

На каждой итерации `name` получает название товара, а `count` получает его количество. Программа выведет пары `apples 3` и `pears 2`, разделённые табуляцией. Порядок строк не гарантируется. Его нельзя выводить из порядка записи полей в конструкторе или порядка добавления.

Для суммы порядок не важен. Накопитель собирает количества независимо от того, какое поле встретится первым.

```lua
local stock = { apples = 3, pears = 2 }
local total = 0
for _, count in pairs(stock) do
    total = total + count
end
print(total) -- 5
```

Для упорядоченного вывода сначала собираем строковые ключи в последовательность, сортируем её и затем читаем значения по этим ключам.

```lua
local stock = { pears = 2, apples = 3 }
local names = {}
for name in pairs(stock) do
    table.insert(names, name)
end
table.sort(names)
for _, name in ipairs(names) do
    print(name, stock[name])
end
```

Первый цикл собирает ключи `stock` в последовательность `names`. После `table.sort(names)` имена идут по алфавиту. Второй цикл читает эти имена через `ipairs` и получает количества из `stock[name]`, поэтому строки выводятся в порядке отсортированных ключей.

```text
apples  3
pears   2
```

Присваивание `stock.apples = nil` удаляет поле. После этого его не будет в обходе. Добавление нового поля во время обхода делает поведение `pairs` неопределённым. Изменять и удалять существующие поля можно. В наших задачах изменение набора данных и обход выполняются отдельными шагами.

Оператор `#` для словаря не считает именованные поля. Если требуется количество таких полей, увеличиваем отдельный счётчик при обходе.
